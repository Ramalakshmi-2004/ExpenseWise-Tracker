# ExpenseWise Tracker – Expense Management System

## About the Project

ExpenseWise Tracker is a web-based Expense Management System developed using ASP.NET Web Forms, C#, ADO.NET, and SQL Server. It helps users manage and track their income and expenses in one place.

## Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** C#, ASP.NET Web Forms
- **Database:** SQL Server
- **Database Connectivity:** ADO.NET
- **IDE:** Visual Studio 2026

## Features

- User Registration and Login
- Session-Based Authentication
- Dashboard for tracking financial information
- Add and manage income records
- Add and manage expense records
- Income and expense history
- Profile management
- Forgot Password functionality
- CRUD Operations (Create, Read, Update, Delete)

## Project Structure

- `Admin/` – Administrative-related files
- `Content/` – Styling and frontend resources
- `Default.aspx` – Default application page
- `Login.aspx` – User login
- `Register.aspx` – User registration
- `Dashboard.aspx` – Dashboard
- `AddIncome.aspx` – Add income records
- `AddExpense.aspx` – Add expense records
- `IncomeHistory.aspx` – View income history
- `ExpenseHistory.aspx` – View expense history
- `Profile.aspx` – User profile
- `ForgotPassword.aspx` – Password recovery
- `Logout.aspx` – Logout functionality

## How to Run the Project

1. Clone or download this repository.
2. Open the solution in Visual Studio 2022.
3. Configure the SQL Server database and connection string in `Web.config`.
4. Restore the required NuGet packages, if needed.
5. Build and run the project using Visual Studio.
